# Notatnik badań: trzy trudne tematy

Publiczny notatnik badań Błażeja. Cel: zebrać twierdzenia, dane pierwotne, publikacje, kontrargumenty i otwarte pytania dotyczące (1) życia pozaziemskiego/UAP, (2) budowy piramid, (3) religii i bogów.

## Zasady pracy

- Oddzielać obserwację od interpretacji oraz hipotezę od potwierdzonego wyniku.
- „Niezidentyfikowane” nie znaczy „pozaziemskie”; „brak dowodu” nie znaczy „dowód nieistnienia”.
- Pierwszeństwo mają dane i publikacje pierwotne, rejestry instytucji, recenzowane prace i archeologia in situ. Media służą głównie do znajdowania tropów i krytyki.
- W tematach spornych szukać również replikacji, krytyki metod i odpowiedzi autorów.
- Każdy wpis oznaczać datą sprawdzenia, statusem dowodu i poziomem pewności.
- Nie obiecywać „przeszukania całego internetu”; wyszukiwanie nie jest kompletne. Dążymy do maksymalnie szerokiego, jawnego i odtwarzalnego przeglądu.

## Stan na 2026-11-26

Wstępny przegląd nie daje jednego wspólnego „sekretnego rozwiązania”. Są trzy odrębne klasy pytań: czy istnieje życie poza Ziemią (empirycznie otwarte), jak dokładnie wykonano niektóre elementy budowy piramid (częściowo otwarte mimo mocnych danych o ludziach i logistyce), oraz czy byty nadnaturalne istnieją (dla ogólnych, nietestowalnych definicji nie jest to pytanie rozstrzygalne metodą nauk empirycznych).
