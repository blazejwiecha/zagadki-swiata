1. Czy źródło udostępnia pierwotny materiał, metodę i niepewność?
2. Czy kompetencje autorów pasują do metody i konkretnego podtematu?
3. Czy praca jest recenzowana? Czy została skorygowana, wycofana lub zreplikowana?
4. Czy niezależne zespoły odtworzyły wynik?
5. Czy nagłówek twierdzi więcej niż sama praca?
6. Jakie obserwacje mogłyby obalić daną hipotezę?
