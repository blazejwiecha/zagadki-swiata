# Rzadkie rozpady mezonów B

Rzadkie rozpady są czułe na hipotetyczne cząstki poza Modelem Standardowym, lecz samo wykrycie rzadkiego kanału nie oznacza nowej fizyki. Trzeba porównać zmierzoną częstość z precyzyjnym przewidywaniem, uwzględnić niepewności i uzyskać potwierdzenie.

## B⁰ → μ⁺μ⁻: sygnał na poziomie dowodu (runda 65)

LHCb zgłosiło pierwszy pojedynczo-eksperymentalny dowód na ten rozpad: 3σ w danych Run 3 i 3,2σ po połączeniu z Run 1–2. Praca korzysta z 18 fb⁻¹ danych z lat 2024–2025 i pozostaje preprintem zgłoszonym do *Physical Review X*. Istotność nie osiąga standardu odkrycia, a współpraca podaje zgodność wyników z Modelem Standardowym. Wcześniejszy, słabszy sygnał nie został potwierdzony przez późniejsze analizy.

Pełna ocena: [dziennik rundy 65](../../research-log/2026-11-27-round-65.md).
